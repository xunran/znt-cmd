# 页面 UI 与服务端接口匹配审计（Origin AgentOps）

审计日期：2026-06-05  
审计对象：`znt--html/ploykit/modules/origin-agentops/components/AgentOpsApp.tsx` 当前前端 UI，以及 `modules/origin-agentops/module.ts` 声明的服务端 API/action。  
实测证据：`znt--html/ploykit/.codex-api-audit/run-20260605023903/api-audit.json`。  

## 判定标准

| 标准 | 含义 |
| --- | --- |
| 可用 | UI 功能已绑定服务端接口，且本地 HTTP 实测通过。 |
| 降级可用 | 接口返回成功，但依赖 CleanCore/ToolHost/外部服务的真实链路未配置，只写入本地降级读模型。 |
| 缺参数 | 有接口，但接口不接收或不处理 UI 所需的筛选、分页、排序、批量、导出、策略等参数。 |
| 缺接口 | UI 展示了功能，但 `module.ts` 没有对应 API/action。 |
| UI 未绑定 | 页面有按钮/控件，但没有 `onClick`、有效跳转或接口调用。 |
| 不可用 | 实测 HTTP 失败，或错误码不满足前端/业务可用性。 |

## 总体结论

| 项目 | 结论 | 证据 |
| --- | --- | --- |
| Origin API route | 21 个 route，50 个方法 | `module.ts:354` 开始的 `routes.api`，以及 `api-audit.json`。 |
| Origin action | 11 个 action | `module.ts:378` 开始的 `actions`。 |
| UI 调用入口 | `/api/modules/origin-agentops` 与 `/api/module-actions/origin-agentops` | `AgentOpsApp.tsx:21-22`。 |
| Origin 实测结果 | 56 条非 cleanup 请求，55 条 pass，1 条 fail | `api-audit.json`。 |
| CleanCore 状态 | `MODULE_SERVICE_CONNECTION_MISSING` | `GET /api/modules/origin-agentops/state` 返回：`CleanCore service connection is not configured. Using workspace demo read models.` |

**核心判断：** 当前 Origin AgentOps 并不是“完全没有接口”。基础 CRUD、运行、审批、追踪、API Key、工具/连接创建都已具备本地可用接口；但大量 UI 设计能力仍停留在静态 UI 或前端本地过滤层，没有完整服务端能力。所有需要真实 CleanCore/ToolHost/外部服务执行的能力目前只能算“降级可用”。

## 横向缺口汇总

| 类型 | 具体缺口 |
| --- | --- |
| 服务端查询参数缺失 | agents/skills/tools/tool-providers/service-connections/runs/approvals/traces 的 GET 接口基本固定 `limit`，不处理 UI 所需 `query/status/type/tag/risk/source/date/page/pageSize/sort`。 |
| 批量能力缺失 | 批量发布/删除/禁用智能体，批量审批，批量导入工具/技能/智能体，批量导出均无接口。 |
| 导出能力缺失 | 运行导出、Trace 证据导出、审计报告导出没有 API。 |
| 策略能力缺失 | 发布策略、审批策略、筛选规则、访问控制策略没有 API。 |
| 真实外部链路缺失 | CleanCore 未配置；ToolHost sync/health/smoke 只是本地降级。 |
| 详情子资源缺失 | 健康记录、使用记录、完整 Trace 时间线、审批审计记录、Agent 访问控制、协作者管理没有独立接口。 |
| UI 文案与实际行为不一致 | “新建审批规则”实际创建审批事项；“保存视图”实际创建 trace event；Agent 列表更多按钮实际删除。 |
| UI 未绑定 | 顶栏搜索、通知、帮助、建议按钮、收起、收藏、复制、下载模板、Quickstart、导出、更多筛选、分页等多处无动作。 |

## 建议补接口优先级

1. **先补列表查询参数**：为主要列表接口统一支持 `query/status/type/tag/risk/source/agentId/dateFrom/dateTo/page/pageSize/sort`，否则页面分页和筛选都是假 UI。
2. **补导出接口**：`/runs/export`、`/traces/export`、`/traces/[id]/evidence`、`/audit-report`。
3. **补策略接口**：`/approval-policies`、`/release-policies`、`/saved-filters`、`/agent-access-policies`。
4. **补成员/协作者接口接入**：Origin 页面至少读取 Host workspace members，Agent 协作者需要绑定关系接口。
5. **补真实连接链路**：配置 CleanCore service connection，并让 ToolHost sync/health/smoke 返回真实外部服务结果。
6. **修 action 错误码**：`runAgent` 空 body 当前返回 HTTP 500 / `MODULE_ACTION_ROUTE_ERROR`，应返回明确业务错误码，如 `ORIGIN_AGENT_ID_REQUIRED`。
